Module 1 › 5 Key Habits
⚡ Maximize Token Efficiency

The Five Habits That Save the Most

1. Edit, Don't Stack: Edit messages instead of sending follow-ups. Saves 70–80% of wasted tokens.

2. New Chat ~15 Msgs: Context compounds. Start fresh after ~15 messages.

3. Batch Into One: Combine all requirements into a single, clear message.

4. Turn Off Burners: Disable Web Search and Artifacts by default.

5. Pace Your Day: Use 3× 90-min sessions instead of one 4-hour marathon.

Result: Together these cut token consumption by 60-70% while improving quality.
Module 2 › Model Selection
🧠 Pick the Right Model

Three-Tier Model System

Haiku (~500 tok): Quick answers, grammar, brainstorming. Use for 80% of work.

Sonnet (~2,000 tok): Writing, coding, analysis. Use for 15% of work.

Opus 4.8 (~8,000 tok): Deep research, hard logic. Use for 5% only.

Golden Rule: Haiku for drafts. Sonnet for real work. Opus for hard stuff.
Module 3 › Configuration
🔧 Memory, Projects & CLAUDE.md

Three Configuration Layers

Memory: Your role, tone, rules. Loads automatically in every chat.

Projects: Upload files once. Claude caches them. Reference for free.

CLAUDE.md: Project file with stack/tone/rules. Reads automatically.

Benefit: Never repeat context again. Saves hours weekly.

Module 5 › Skills Mastery
🎯 Skills Trigger Automatically

What Are Skills?

Specialized instruction bundles for specific tasks. When you mention a task, Claude automatically consults the relevant skill.

High-Priority: pptx, docx, xlsx, pdf, doc-coauthoring, theme-factory

By Domain: Finance (financial-statements, reconciliation), Marketing (campaign-plan, seo-audit), Sales (pipeline-review, forecast), Legal (contract-review, nda-triage)

Module 5 › Plugins
🔌 Bundles for Your Role

What Are Plugins?

Bundles of skills + MCP servers for specific roles. Install once, access all tools automatically.

  • Small Business: QuickBooks, PayPal, HubSpot for cash flow, invoicing, payroll
  • Finance: DCF modeling, comps analysis, earnings reports
  • Marketing: Campaign planning, email sequences, SEO audits
Setup: Go to Settings → Plugins. Search your role. Install once.
